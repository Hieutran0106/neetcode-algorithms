# NeetCode Algorithm Learning

Website cung cấp kiến thức nền tảng về thuật toán
và cấu trúc dữ liệu theo NeetCode Roadmap.

## Nội dung

Website gồm 18 chương:

1. Array & Hashing
2. Stack
3. Two Pointers
4. Binary Search
5. Sliding Window
6. Linked List
7. Trees
8. Tries
9. Backtracking
10. Heap / Priority Queue
11. Intervals
12. Greedy
13. Graphs
14. Advanced Graphs
15. 1-D Dynamic Programming
16. 2-D Dynamic Programming
17. Bit Manipulation
18. Math & Geometry

## Công nghệ

- React
- Vite
- JavaScript
- CSS

## Hướng dẫn chạy

```bash
npm install
npm run dev
```

Sau đó truy cập http://localhost:5173
